### Почему такой порядок
- **HTML и CSS до Django:** без них шаблоны и формы Django непонятны. Минимум HTTP (URL, запрос и ответ, `GET`/`POST`, коды, cookies, HTTPS) идёт первым разделом этого курса: он нужен Django с первой темы (`request`, `redirect`, сессии, CSRF).
- **SQL до Django:** ORM изучается после SQL, задачи ORM повторяют задачи SQL — ученик видит соответствие.
- **Терминал и Git — короткий минимум перед Django:** чтобы запустить Django у себя и сохранить работу. Полный Linux — перед Docker, где он действительно нужен (сервер); глубокий Git — дополнительный модуль.
- **Веб и API после Django:** REST, токены и CORS понятнее, когда ученик уже сделал страницы и CRUD на Django; курс ведёт к DRF и FastAPI.

## Исправить в источниках при написании (⚠️)
- SQL: «кластеризованные индексы» — термин MySQL/SQL Server, к PostgreSQL не относится; пример Phantom Read для MySQL заменить на PostgreSQL.
- Python: «ключом может быть только неизменяемый тип» и «при коллизии корзина хранит несколько пар» (`03_dicts_and_sets.md`) — неточно, исправлено в пилоте.
- Git: вероятно, старые `checkout`/`reset HEAD` → даём `switch`/`restore`.
