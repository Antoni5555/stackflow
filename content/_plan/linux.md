# Курс: Linux — шаг 70

**Зачем:** работа на сервере — то, без чего не обойтись в Docker и деплое. Основы терминала (навигация, файлы, запуск Python, `venv`, `pip`) уже пройдены в курсе «Терминал и Git: старт» перед Django; здесь — всё, что нужно на сервере.
**Контекст:** ученик получил доступ к серверу магазина. Код лежит в `/srv/shop`, логи — в `/var/log/shop` и `/var/log/nginx`, конфиги — в `/etc/nginx`, медиафайлы товаров — в `/srv/shop/media/products`. Задачи — реальные дела на сервере: найти ошибку в логе, сделать бэкап, поправить права, перезапустить сервис.
**Тренажёр:** симулятор shell + дерево файлов с подсветкой изменений. Команды для тем 1.02 (`head/tail -n`), 1.04 (`ln -s`), 2.01 (`find -type/-size`), 2.02 (`grep -v`), 2.03 (`2>`, `2>&1`, `/dev/null`), 2.04 (`cut -d -f`, `sort -n -r`), 2.05 (`tar`), 3.02 (`chmod u+x`), 3.03 (`chown -R`, владелец файлов) «Разработка» добавляет на этапе 5 — эти темы делаем задачами в тренажёре. Формат задач — `docs/content-format.md`, «exercise с проверкой состояния».
**Опирается на:** Терминал и Git: старт (раздел «Терминал»), Django (что запускаем на сервере), Веб и API (порты, `curl`).
**Источники:** почти нет — `training_skills/connect_to_github.md`, `connect_to_server.md` (SSH), `nginx_gunicorn.md` (права, `.env`, systemd по ходу деплоя). Курс пишется с нуля.

Формат — [docs/content-format.md](../../docs/content-format.md), легенда — [00-overview.md](00-overview.md).
