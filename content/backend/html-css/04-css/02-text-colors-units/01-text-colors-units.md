## Теория
Текст оформляют несколько свойств: `font-family` — шрифт (список запасных через запятую, последним — общий вид `sans-serif`), `font-size` — размер, `font-weight` — жирность (400 — обычный, 700 — жирный), `line-height` — высота строки, `color` — цвет текста, `text-align` — выравнивание. Фон задаёт `background-color`.

Цвет записывают по-разному: словом (`red`), шестнадцатеричным кодом (`#2e7d32`, коротко `#fff`), функцией `rgb(46, 125, 50)`. Браузер внутри всё равно хранит его как `rgb(…)` — это видно в DevTools в разделе Computed.

**Единицы размеров:**
- `px` — точная величина. Подходит для рамок и мелких отступов.
- `rem` — доля размера шрифта корня страницы (`html`), по умолчанию 16px: `1.5rem` = 24px. Если покупатель увеличил шрифт в настройках браузера, всё в `rem` вырастет вместе с ним. Поэтому размеры текста задают в `rem`.
- `em` — доля размера шрифта самого элемента; удобно для отступов «от текста», но вложенные `em` перемножаются.
- `%` — доля от родителя: `width: 50%` — половина ширины родителя.

**Переменные CSS** убирают повторы. Цвета магазина объявляют один раз в `:root` (это `html`) и используют через `var()`: `--accent: #2e7d32;` → `color: var(--accent);`. Поменяли значение в одном месте — поменялось везде. Переменные наследуются, поэтому переопределение внутри блока действует только на этот блок. На этом построены светлая и тёмная темы.

## Наглядно
**Таблица 1.** Как записывают и как браузер отдаёт значения (вкладка Computed в DevTools).

| Записано в CSS | Вычисленное значение |
|---|---|
| `color: green` | `rgb(0, 128, 0)` |
| `color: #2e7d32` | `rgb(46, 125, 50)` |
| `font-weight: bold` | `700` |
| `font-size: 1.5rem` (корень 16px) | `24px` |
| `font-size: 2em` (родитель 14px) | `28px` |
| `color: var(--accent)` | значение переменной, например `rgb(46, 125, 50)` |

**Таблица 2.** Какую единицу брать.

| Что задаём | Единица | Почему |
|---|---|---|
| размер текста | `rem` | растёт с настройкой шрифта браузера |
| ширина колонки | `%` | зависит от ширины родителя |
| рамка, тонкая линия | `px` | должна быть ровно в 1px |
| высота строки | число без единицы, `1.5` | считается от шрифта каждого элемента |

## На практике
Задача: собрать цвета и шрифт магазина в одном месте и применить их к карточке товара.

### Шаг 1. Объявляем переменные
Все цвета магазина — в начале файла стилей:
```css
:root {
  --text: #1b1b1b;
  --muted: #6e6e6a;
  --accent: #2e7d32;
  --surface: #ffffff;
}
```
Имена — по роли цвета (`--accent`), а не по самому цвету (`--green`). Иначе после смены зелёного на синий имя начнёт врать.

### Шаг 2. Задаём базовый текст
Шрифт и цвет наследуются, поэтому их достаточно задать `body`:
```css
body {
  font-family: Manrope, Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
  color: var(--text);
  background-color: var(--surface);
}
```
Если шрифта Manrope у покупателя нет, браузер возьмёт Arial, а если нет и его — любой шрифт без засечек.

### Шаг 3. Оформляем карточку
Заголовок крупнее, цена — акцентным цветом, артикул — приглушённым:
```css
.card-title {
  font-size: 1.25rem;
  font-weight: 600;
}

.price {
  color: var(--accent);
  font-weight: 700;
}

.sku {
  color: var(--muted);
  font-size: 0.875rem;
}
```
`1.25rem` — 20px, `0.875rem` — 14px при обычной настройке браузера.

### Шаг 4. Меняем акцент в одном месте
Магазин сменил фирменный цвет на синий — правим одну строку:
```css
:root {
  --accent: #1565c0;
}
```
Цена, кнопки и ссылки, которые используют `var(--accent)`, перекрасятся сами.

## Частые ошибки
- **Размер текста в `px`.** Покупатель со слабым зрением увеличил шрифт в браузере — а текст сайта остался мелким. Текст — в `rem`.
- **`line-height: 24px`.** Фиксированная высота строки не растёт вместе со шрифтом, крупный заголовок налезает строками друг на друга. Пишут число: `1.5`.
- **Опечатка в имени переменной.** `var(--acent)` не выдаёт ошибку — свойство просто не применяется. Помогает запасное значение: `var(--accent, #2e7d32)`.
- **Нет общего вида шрифта в конце.** `font-family: Manrope;` без `sans-serif` — у кого шрифта нет, тот увидит шрифт с засечками по умолчанию.
- **Вложенные `em`.** `font-size: 1.2em` у списка внутри списка даёт 1.2 × 1.2. Для размеров текста надёжнее `rem`.

## Итог
**Текст**
- `font-family` со списком запасных и общим видом в конце; `font-size`, `font-weight` (400/700), `line-height` числом, `color`, `text-align`.
- Шрифт и цвет наследуются — задаём у `body`.

**Цвета**
- Слово, `#rrggbb`, `rgb()`; внутри браузера — всегда `rgb(…)`.

**Единицы**
- `rem` — текст; `%` — доля родителя; `px` — рамки; `em` — от своего шрифта.

**Переменные**
- Объявляем в `:root`, используем через `var(--имя)`.
- Имена — по роли цвета; одно место для изменения всего сайта.

## Вопросы на собеседовании
<details><summary>Чем `rem` отличается от `em`?</summary>

`rem` считается от размера шрифта корня (`html`) и одинаков во всём документе. `em` — от размера шрифта самого элемента (для `font-size` — от родителя), поэтому вложенные `em` перемножаются. Для размеров текста обычно берут `rem`, `em` — для отступов, которые должны расти вместе с текстом элемента.
</details>

<details><summary>Зачем нужны переменные CSS?</summary>

Чтобы задать значение один раз и использовать его везде: цвета, отступы, шрифты. Смена дизайна — правка одного места. Переменные наследуются и переопределяются для части страницы или по классу темы — так делают тёмную тему без дублирования правил.
</details>

<details><summary>Почему `line-height` пишут без единиц?</summary>

Число без единиц наследуется как множитель и пересчитывается от шрифта каждого элемента. Значение в `px` или `em` наследуется уже вычисленным, и у крупного заголовка строки окажутся слишком тесными.
</details>
