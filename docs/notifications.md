# Оповещения в Telegram

Все сайты автора пишут в один чат (бот деплоев), поэтому сообщения устроены одинаково: по первой строке сразу видно, **какой сайт** и **что случилось**.

Отправка — `deploy/notify.sh <уровень> <событие> < тело`: шапку и подвал скрипт добавляет сам, тело — строки «Ключ: значение».

## Формат

```
<значок> <b>НАЗВАНИЕ САЙТА</b> · <событие>
<code>домен</code>

Ключ: значение
Ключ: значение

<b>Блок</b>            ← необязательные блоки с заголовком
• пункт

<ссылки через « · »>
<i>ДД.ММ.ГГГГ ЧЧ:ММ МСК</i>
```

- Название сайта — заглавными, как в `SITE_NAME` (STACKFLOW). Домен — второй строкой.
- Событие — 2–3 слова: «Деплой завершён», «Деплой не прошёл», «Сайт не работает», «Снова работает», «Нужно внимание».
- Значок шапки — уровень; в теле значки только как отметки этапов и контейнеров (✅ ❌ ⏭).
- Разметка — HTML Telegram (`parse_mode=HTML`); `& < >` в данных экранируются. Превью ссылок выключено.
- Время — московское.

## Уровни

| Значок | Уровень | Когда |
|---|---|---|
| ✅ | `ok` | действие прошло (деплой) |
| ❌ | `fail` | действие не прошло, сайт работает как раньше |
| 🔴 | `down` | сайт или его часть не работает |
| ⚠️ | `warn` | сайт работает, но скоро будут проблемы (диск, сертификат) |
| 🟢 | `up` | сбой закончился |
| ℹ️ | `info` | просто к сведению |

## События STACKFLOW

**Деплой** (CI, job `notify`, после каждого пуша в `main`): коммит (ссылка, короткий SHA и первая строка сообщения), автор и ветка, этапы (проверка · тесты · образы · выкатка), длительность; при падении — «Сайт работает на прошлой версии». Ссылки: сайт, лог сборки.

**Мониторинг** (`deploy/monitor.sh`, cron каждые 10 минут): проблемы (диск ≥ 80 %, контейнер не healthy, главная не 200) — блок «Проблемы» + «Сервер» (диск, память, нагрузка, контейнеры) + команда для проверки. Перед тревогой — повторная проверка через 90 секунд (перезапуск при деплое не считается). Одна и та же проблема — одно сообщение; когда прошла — 🟢 с длительностью сбоя.

Токен и чат: в GitHub — секреты `TG_TOKEN`, `TG_CHAT_ID`; на сервере — `~/.notify.env` (права 600).
